# Group B — Review the planned PC pathway

**Time:** About 5–10 minutes  
**Who this is for:** Everyday PC owners; technical knowledge is not required  
**Status:** This pathway is a planned concept and is not available on the website yet.

We are testing whether the idea and language are useful. Do not send your computer's serial number, account details, screenshots or other identifying information.

## Scenario

Imagine you have a working Windows 10 PC. You want to know whether you can keep using it with Windows 11, whether a setting or part needs attention, or whether the available information is incomplete.

Structura would ask for the PC model and any relevant configuration you know. It would then show one of these results:

- Requirements are evidenced as met.
- A configuration check is needed.
- A replaceable component may block readiness.
- A platform requirement is not met.
- The evidence is unknown or conflicting.

The result would include a simple hardware path and links to the evidence behind each finding.

## Questions

1. What information would you expect to enter or select first?
2. Which result label is least clear? How would you rewrite it?
3. What would you need to see before trusting the result?
4. Would you open the supporting evidence? Why or why not?
5. After receiving a result, what would you expect Structura to help you do next?
6. Would this be useful to you or someone you know? Give one reason.
