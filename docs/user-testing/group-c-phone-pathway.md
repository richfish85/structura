# Group C — Review the planned phone pathway

**Time:** About 5–10 minutes  
**Who this is for:** Anyone who uses a smartphone and has chosen, borrowed or replaced a charger or cable  
**Status:** This pathway is a planned concept and is not available on the website yet.

We are testing whether the idea and language are useful. Do not send serial numbers, IMEI numbers, account details, receipts or screenshots containing personal information.

## Scenario

Imagine you have your phone, a USB-C charger and a cable, but you do not know what the combination will do. You want to know whether it connects, charges normally or supports the fast-charging mode you expect.

Structura would ask you to identify the phone, charger and cable. Saying **I don't know which cable this is** would be allowed. It would then show one of these results:

- The physical connection fits.
- Ordinary charging is evidenced.
- A named fast-charging mode is evidenced.
- It works with a documented limit.
- A required capability is missing.
- The evidence is unknown or conflicting.

The result would show the phone–cable–charger path and the evidence behind each link.

## Questions

1. Which of the phone, charger and cable would be hardest for you to identify?
2. Which result label is least clear? How would you rewrite it?
3. What would you need to see before trusting the result?
4. Would you open the supporting evidence? Why or why not?
5. What other phone-related task would you expect Structura to answer next?
6. Would this be useful when buying, borrowing or reusing accessories? Give one reason.
