# First Connected Explorer

Status: local implementation delivered; real-person trial pending, 2026-09-09. Approved from the owner's consolidated Sol/Astra brief.

## What

Turn Structura into a navigable hardware reference using one deeply connected object as the proving ground. Keep the 1997/1998 launch-cohort research as a historical catalogue. The first user is a technically curious learner following a device's structure and evidence.

## Why

The research pipeline is useful but does not yet demonstrate connected hardware understanding. Research now follows questions exposed by the explorer.

## How

Preserve Python, SQLite, immutable source packets, provisional records and a read-only interface. Deliver a local reference-site checkpoint with restrained typography, breadcrumbs, search, dossiers and a functional 2D schematic. Publication and licensing remain separate from this local milestone.

### Acceptance checklist

- [x] Correct the 1997 audit handoffs in new, traceable coordinator artifacts.
- [x] One command validates packets, rebuilds SQL, checks integrity and generates the explorer and truthful status.
- [x] Search, year/category/manufacturer browsing, sources, discrepancies, method and sitemap.
- [x] Readable dossiers for both historical cohorts.
- [x] One documented M.2 NVMe SSD, approximately 15–30 sourced typed relationships.
- [x] Components in a 2D schematic link to stable entities; users can follow a relationship.
- [x] Claim-level evidence, one comparison and one meaningful unresolved question.
- [x] Automated data/build tests and browser/keyboard/narrow-screen checks.
- [ ] Real-person usability trial. This is pending until actual participants use it; agent checks do not substitute.

## Assumptions and boundaries

The sample counts, Samsung model and component positions in the brief are illustrative, not evidence. Prefer Samsung 970 EVO 500 GB if primary documentation supports it. A schematic is not a teardown image or a claim about actual package placement. Candidate relationships remain explicitly provisional and are not blanket compatibility assertions.

No Neo4j, CAD/3D, accounts, crowdsourcing, prices, scores, AI search, mass census expansion or elaborate branding in this milestone.

## Validation and risks

Require the full unit suite, clean initialization/integrity checks, repeated builds and invalid-packet failure without changing the current checkpoint. Browser testing covers navigation, search, component/relationship/evidence paths and responsive readability. Independent research checks must remain distinct from canonical human approval. Record licensing, unresolved claims and real-user testing honestly.
