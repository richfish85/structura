# Scout Notes — Mobile and Upgrade CPU Omission Slice

Scope completed: all six assigned keys were researched. No additional candidates were added and no existing candidate was normalized, verified, or promoted.

## Evidence notes

- Intel's April 2, 1998 first-party release explicitly introduces the first mobile Pentium II processors at 233 and 266 MHz. It says Pentium II processor-based mobile PCs are available beginning today and gives separate 1,000-unit mini-cartridge and mobile-module pricing. Keep these as mobile speed-grade leads with exact introduction and same-day system-availability wording.
- Intel's historical chronology lists Mobile Intel Pentium II Processor 300 MHz on September 9, 1998. Intel's September 16 release describes it as recently introduced but supplies no exact availability event. Preserve the chronology date as an introduction date and leave release timing unknown.
- Intel's OverDrive release is dated August 10, 1998. One product is described as upgrading 150/180-MHz Pentium Pro systems to 300 MHz and 166/200-MHz systems to 333 MHz. Availability is a range (second half of August), and reseller/distributor purchase is stated. Keep 300 and 333 as separate output-speed leads but retain the shared upgrade-product wording.
- AMD's filed Q3 results exhibit (press release dated October 6, 1998; filing published October 23) says, “During the quarter we also introduced a 300MHz AMD-K6 processor for mobile applications.” This is quarter-precision introduction evidence for Q3 1998; first shipment, system/component channel, and geography are not stated.

## Segment and identity boundaries

Mobile and upgrade are explicitly in scope for this pilot but must remain separately labeled. Frequency/output speed is preserved as manufacturer wording, not treated as proof of a distinct ordering part number. The two OverDrive rows may represent one physical upgrade product with two supported upgrade outcomes; this is a verifier/granularity question, not a scout conclusion.

## Limitations and follow-up

All consulted evidence is manufacturer-controlled primary evidence. Intel chronology is historical first-party reference material, and the AMD source is a later regulatory filing reproducing a contemporary release. Exact Intel part numbers, package identifiers, geographical sell-through, and AMD commercial availability remain unresolved where not stated. Independent verification should confirm identity granularity and typed commercial events before normalization.
