# Scout Notes — Desktop/Server CPU Omission Slice

Scope completed: all six assigned keys were researched. No additional candidates were added and no existing candidate was normalized or verified.

## Evidence notes

- Intel's first-party chronology provides exact 1998 introduction dates for all four Intel omission leads, but only the Pentium II 333, Celeron 300, and Xeon 450 have a directly linked contemporary press release in this run.
- Intel Pentium II 333 has exact introduction and same-day system availability on 1998-01-26; server/workstation availability is explicitly later in the quarter.
- Intel Pentium 266 remains an introduction-only lead because the consulted chronology does not state commercial availability or channel scope.
- Intel Celeron 300 is explicitly plain 300 MHz and should not be merged with Celeron 300A. The June release identifies same-day system announcements but does not provide a precise component/boxed availability date.
- Intel Pentium II Xeon 450 is an October 6 announcement/introduction. Two-way system shipments were planned later in October; four-way availability was explicitly deferred to early 1999. Preserve this channel split.
- AMD's January 1999 filed release is retrospective. It supports Q4 1998 introduction and volume shipment for both 366 MHz and 380 MHz, but not an exact day/month or first-shipment date.

## Limitations

All consulted evidence is manufacturer-controlled primary evidence. The Intel chronology is historical first-party reference material, and the AMD source is a later company filing. No independent confirmation was required by the job policy. Part numbers, package variants, cache configurations, geographic sell-through, and exact commercial availability remain unresolved where not stated.
