# Expansion Report 05 — Twelve CPU Omission Leads

## What

The twelve approved-scope omission keys were divided into two disjoint Luna scout jobs and then checked by a different Terra verifier over frozen, hashed inputs. All results remain non-canonical.

## Why

The first ten rows proved the pipeline but did not form a complete Intel/AMD launch cohort. This expansion tests whether the file-based job protocol can add bounded research capacity while preserving worker identity, source wording, uncertainty, and independent stage separation.

## How

- Desktop/server scout: six Intel/AMD keys, six completed, five first-party sources.
- Mobile/upgrade scout: six keys, six completed, six first-party sources.
- Independent verifier: twelve keys attempted and completed, using only the frozen scout source registers.
- Every job has a coordinator-owned job manifest and an immutable run directory containing result manifest, hashes, output rows, and method notes.
- SQL intake resolves stable source identity by key or URL while preserving each worker's raw source-register wording separately.

## Verification outcome

Nine keys receive `retain_for_human_review`. AMD K6-2 366/380 and AMD-K6/300 mobile remain quarter-precision. Mobile Pentium II 233/266 have exact introduction plus same-day system/component availability. Mobile Pentium II 300 and Pentium 266 rely on Intel's retrospective chronology for exact introduction dates. Xeon 450 is a separate `review_required` result.

### OverDrive identity flag

Intel's source describes one singular Pentium II OverDrive processor with two output mappings: 300 MHz for some Pentium Pro inputs and 333 MHz for others. The frozen `intel-pentium-ii-overdrive-300` and `intel-pentium-ii-overdrive-333` scout keys should not be approved as two physical products without contrary part-number evidence. Recommended review action: replace them with one product candidate plus compatibility/output assertions, retaining both frozen rows as provenance.

### Xeon 450 event flag

The current source gives an exact 1998-10-06 announcement and planned two-way system shipments later in October; four-way availability is placed in early 1999. Recommended review action: keep `intel-pentium-ii-xeon-450` as `review_required` unless later evidence establishes an accepted 1998 introduction or completed commercial shipment, or the cohort event rule is broadened to include announcement plus dated imminent shipment.
