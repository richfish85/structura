# 1997 CPU Normalization Notes

## Scope

This run proposes normalized labels for exactly the nine candidates in the verified 1997 CPU slice. It does not add candidates, alter scout or verification artifacts, audit the cohort, conduct context research, or promote canonical records. Access date: 2026-09-08.

## Boundary decisions

- Intel Pentium II and desktop Pentium MMX speed grades are model variants, with no invented parent candidate because the family was not separately staged.
- Mobile Pentium MMX 200/233, mini-notebook 120, and embedded 200 remain separate segment/application records. Mobile and embedded wording is retained in channel notes and not merged with desktop records.
- AMD-K6 remains a family-level record with quarter precision because the verified filing confirms Q2 1997 volume shipments but does not enumerate speed grades or an exact launch day.
- The Pentium II 300 MHz record retains exact family introduction date but a workstation-channel gap; the embedded 200 MHz record remains SKU-unresolved because application/module wording does not establish a boxed CPU SKU.
