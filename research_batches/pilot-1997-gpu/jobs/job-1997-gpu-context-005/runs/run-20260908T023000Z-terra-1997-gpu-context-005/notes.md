# 1997 GPU context notes

All six frozen GPU candidates have one product-intent claim, using only their registered scout sources. NVIDIA, S3, Canopus, Melco, and ATI claims preserve source-level positioning; PERMEDIA 2 is explicitly marked as an interpretation from an ELSA board-maker release rather than a 3Dlabs purpose statement.

`benchmarks.csv` is intentionally header-only. The registered evidence provides no common disclosed workload, driver revision, test system, and result provenance for fair comparison across chips and boards. No performance, price, or shipment comparison is inferred from product descriptions.

This packet is context-only and non-canonical. It does not add candidates, revise normalization or verification, or change any database/shared batch artifact.
