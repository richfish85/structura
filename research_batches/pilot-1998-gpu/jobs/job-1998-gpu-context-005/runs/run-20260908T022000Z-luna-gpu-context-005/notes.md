# GPU Context Notes

All eight frozen GPU keys are covered. Intel launch material supplies explicit purpose claims; Matrox, ATI, and 3Dfx context comes from contemporary technical reporting. NVIDIA's first-party chronology establishes identity and timing but leaves purpose/engineering-response gaps.

`benchmarks.csv` is intentionally empty. No shared disclosed test system, driver, workload, and provenance supports defensible comparisons across these chip and board records.
