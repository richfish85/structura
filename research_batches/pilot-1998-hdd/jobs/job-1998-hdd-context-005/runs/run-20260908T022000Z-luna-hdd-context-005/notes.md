# HDD Context Notes

All four frozen HDD keys are covered with manufacturer-stated purpose claims. Quantum evidence emphasizes capacity, interfaces, form factors, and OEM desktop use; IBM evidence emphasizes very high desktop capacity, spindle speed, and Ultra ATA/66.

`benchmarks.csv` is intentionally empty. The frozen evidence set does not provide a shared disclosed test system, workload, driver/firmware context, and independent provenance for defensible cross-drive comparison.
